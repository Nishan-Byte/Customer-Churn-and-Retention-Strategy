# Data

This directory contains the dataset used for the Customer Churn & Retention Strategy project.

## Dataset

- **Dataset:** Telco Customer Churn Dataset
- **Rows:** 7,043
- **Columns:** 21
- **Target:** Churn
- **Raw format:** CSV

The dataset contains customer demographics, account information, subscribed services,
billing information, and churn status.

## Data Privacy

The dataset is used for educational and analytical purposes. No personally identifiable
information beyond the dataset's provided customer identifiers is used for analysis.
